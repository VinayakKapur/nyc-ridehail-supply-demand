NYC Ride-Hailing Supply-Demand

Interactive geospatial visualizations from a machine learning project predicting taxi and ride-hailing vehicle supply in Lower Manhattan using NYC TLC trip record data.

scikit-learn Folium Pandas Geohash NYC TLC Data

Pickup Density Map

Per-geohash cell pickup counts across Lower Manhattan. Explore spatial demand distribution.

Dropoff Density Map

Pickup Heatmap

Continuous heat overlay of pickup intensity across the borough.

Pickup Heatmap v2

Refined heatmap with updated data preprocessing and smoothing parameters.

Geohash Grid Map
